# Instruções de execução

1. Abra esta pasta no VS Code.
2. Confirme que `Base Varejo.csv` está ao lado do script.
3. Abra o terminal integrado em `Terminal > New Terminal`.
4. Crie o ambiente virtual:

```powershell
python -m venv .venv
```

5. Ative o ambiente no Windows:

```powershell
.venv\Scripts\activate
```

6. Instale as dependências:

```powershell
python -m pip install -r requirements.txt
```

7. Execute o projeto:

```powershell
python Miniprojeto_Varejo_Ednelson_Rocha_da_Silva.py
```

8. Consulte os arquivos gerados na pasta `saidas`.

Para usar o Jupyter, abra `Miniprojeto_Varejo_Ednelson_Rocha_da_Silva.ipynb`, selecione o kernel `.venv` e clique em `Run All`.
